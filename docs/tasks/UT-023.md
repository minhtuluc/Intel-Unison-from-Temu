# UT-023 — Frontend: chọn người nhận, hộp thư Incoming, quản lý relay cho host

Status: in-progress (chờ QC)
Depends on: UT-021, UT-022
Owner / file ownership: `public/js/transfer.js`, `public/js/app.js`, `public/js/relay-inbox.js` (mới), `public/index.html`, `public/css/components.css`

Problem and evidence: trước M4 không có chỗ nào để chọn người nhận, không có màn hình cho người nhận thấy file đang chờ, và host không thấy relay nào đang chạy. `_requestConsent` chỉ gọi `/api/transfer/offer`.

In scope: picker "Send to" trong Upload view (mặc định Host, giữ nguyên hành vi cũ); `_requestConsent` rẽ nhánh relay; xử lý `relay:decision`/`relay:offer:expired` trong engine; modal relay chỉ hiện trên thiết bị nhận; view "Incoming" liệt kê file và tải bằng capability đã lưu; card "Relay transfers" cho host (metadata + Stop, **không** có nút tải).

Out of scope: auto-accept/ghi nhớ thiết bị cho relay; kéo-thả vào picker; hiển thị tiến độ tải của receiver.

Acceptance criteria: không chọn gì → luồng host cũ không đổi; chọn thiết bị → POST `/api/relay/offer` kèm `receiverDeviceId`; task không lên đường truyền trước khi receiver chấp nhận; receiver từ chối → task `rejected`; offer hết hạn → task `error` với câu chữ rõ; receiver offline → task `error` chứ không treo; capability được giữ trong `sessionStorage` và gắn vào URL tải; host không thấy nút tải nào cho file relay.

Regression scenario: `tests/unit/relay-inbox.test.js` (lưu capability, URL tải, load, quyết định, render rỗng/có file); `tests/unit/transfer-consent-engine.test.js` describe "M4 TransferEngine relay consent"; `tests/unit/toast.test.js` (mọi `showToast` dùng dạng object).

Verification commands and actual results: `node --test tests/unit/relay-inbox.test.js` — 8/8 pass; `node --test tests/unit/transfer-consent-engine.test.js` — 21/21 pass; `npm run quality` — 510/510, exit 0.

Remaining risks and handoff: **chưa kiểm trên browser/thiết bị thật** — DOM test dùng `tests/helpers/fake-dom.js`, không thay thế được 3 browser context thật; modal relay và picker chưa được xem bằng mắt. CSS mới chỉ ở mức tối thiểu.

QC vòng 1 (`REVIEW-M4-QC.md`): M4-QC-05 (P2) **đã sửa** wording ở `relay-inbox.js`/`app.js` (không còn tuyên bố host "không đọc được"); view Incoming giờ refresh khi nhận `relay:stored`/`relay:expired` sau khi M4-QC-04 được vá.
