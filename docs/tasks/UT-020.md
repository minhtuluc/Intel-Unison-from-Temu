# UT-020 — Khóa danh tính client

Status: in-progress (chờ QC)
Depends on: —
Owner / file ownership: `src/utils/client-identity.js` (mới), `src/services/discovery.js`, `src/websocket/handlers.js`, `src/websocket/index.js`, `public/js/connection.js`

Problem and evidence: danh tính client chỉ là `connectionId` do `randomUUID()` sinh cho từng socket (`src/websocket/index.js`). Reconnect tạo connectionId **và** device record mới, nên không thể gửi cho "một thiết bị" ổn định — M4 cần một danh tính bền để route offer và làm ACL tải. Bằng chứng: `tests/integration/websocket.test.js` trước M4 chỉ khẳng định `connectionId` được cấp, không có khái niệm khóa bền.

In scope: suy ra tập khóa danh tính từ thông tin server **xác minh được** (`conn:`/`dev:`/`sess:`); index trong `DiscoveryService`; `client:register` mang `deviceToken`; bỏ khóa `sess:` khi session bị thu hồi.

Out of scope: mọi thay đổi ACL/relay (UT-021/022); đổi cách `resolveSender` phân quyền; lưu device token thô ở server.

Acceptance criteria: khóa chỉ sinh từ session đã verify hoặc device token đúng dạng 64-hex; `X-Connection-Id` **không** tạo khóa nào; token sai dạng không suy biến thành khóa dùng chung; reconnect giữ được khóa `dev:`; session revoke làm khóa `sess:` ngừng resolve ngay; registration bị từ chối không để lại khóa trong index.

Regression scenario: `tests/unit/client-identity.test.js` (hash, dạng token, suy giảm, giao tập khóa, không nhận `X-Connection-Id`); `tests/unit/discovery.test.js` (index, thay khóa khi re-register, xóa khi disconnect, cap thiết bị, clear); `tests/integration/websocket.test.js` (register kèm `deviceToken` rồi index biến mất khi socket đóng); `tests/integration/relay-transfer.test.js` describe "durable identity without a PIN".

Verification commands and actual results: `npm run quality` — 510/510 pass, exit 0, coverage 95,43% line / 86,84% branch / 93,99% function (cùng lượt M4).

Remaining risks and handoff: danh tính `dev:` dựa trên `localStorage`; xoá storage là mất khả năng nhận lại file đang chờ. Chưa kiểm trên browser thật (chỉ unit + integration WS).
