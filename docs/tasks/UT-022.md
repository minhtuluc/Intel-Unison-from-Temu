# UT-022 — Lưu file relay, ACL tải, TTL và quota

Status: in-progress (chờ QC)
Depends on: UT-021
Owner / file ownership: `src/services/share-manager.js`, `src/middleware/download-acl.js` (mới), `src/routes/transfer.js`, `src/services/relay-transfer.js`, `src/runtime.js`

Problem and evidence: `GET /api/download/:fileId` chỉ đi qua `requireSession` (no-op khi PIN tắt) và `shareManager.getFile()` — **không có ACL**: bất kỳ client đã xác thực nào cũng tải được mọi file. `GET /api/shared` liệt kê toàn bộ staging. Nếu chỉ thêm receiver vào offer mà không chặn download thì "gửi riêng cho B" vẫn là công bố cho cả LAN.

In scope: `acl` trên record staging (`mode: 'public' | 'receiver'`); `/api/shared` loại file relay; lưu file relay ở `tempDir/relay` (không vào `uploadDir`); TTL `relayTtlMs` → xoá + release quota; sweep + reconcile quota gồm thư mục relay; ACL tải (identity key hoặc `?rt=` hash-only, không bypass cho host); nhánh relay cho cả simple upload và chunked upload.

Out of scope: thumbnail/preview cho file relay; nén/archive; nhiều receiver cho một file.

Acceptance criteria: byte relay không bao giờ nằm trong `uploadDir`; file relay không xuất hiện trong `/api/shared`; receiver tải được bằng `?rt=` **và** bằng `X-Device-Token`, range 206 vẫn đúng; observer, host và token sai đều bị từ chối; hết TTL thì file mất và `quotaTracker.allocatedBytes` trả về đúng mức trước đó; host revoke xoá được file mà không đọc được nội dung; retry `complete` relay không ghép/tạo file thứ hai.

Regression scenario: `tests/integration/relay-acl.test.js` (lưu trữ, ACL, range, incoming list, chunked relay, revoke, TTL + quota); `tests/unit/relay-transfer.test.js` (TTL, quota release, markDownloaded, revoke, capability constant-time).

Verification commands and actual results: `node --test tests/integration/relay-acl.test.js` — 9/9 pass; `npm run quality` — 510/510, exit 0, coverage 95,43 / 86,84 / 93,99.

Remaining risks and handoff: khi PIN tắt, capability nằm trong URL (`?rt=`) nên có thể lọt vào lịch sử trình duyệt của chính máy nhận; đã giới hạn bằng TTL và bind theo từng file, ghi trong ADR-0004. Quota của file relay được release khi xoá; nhánh lỗi giữa `atomicMove` và `attachStoredFile` cần QC soi kỹ.
