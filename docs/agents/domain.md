# Domain documentation

Single-context. Đọc `CONTEXT.md` trước khi đổi hành vi, đọc ADR liên quan trong `docs/adr/`, đối chiếu ID trong `REPORT-ROADMAP.md`.

Phân biệt hiện trạng đã kiểm chứng, quyết định đã chấp thuận, đề xuất và điều chưa biết. Không mô tả roadmap như tính năng đã ship. Thay đổi invariant cần cập nhật domain và ADR; không âm thầm đổi nghĩa host, receiver, relay hoặc P2P.
